# DriveSimPDD

Учебный 3D-симулятор ПДД на Godot 4.

Первый прототип: автомобиль класса Hyundai Solaris с габаритами 4,405 × 1,729 × 1,469 м, управление, двигатель, ремень, ручник, ДХО, поворотники, аварийка, учебная парковка и последовательность действий перед выездом.

## Управление

- `E` — двигатель
- `B` — ремень безопасности
- `Space` — ручной тормоз
- `L` — дневные ходовые огни
- `W/S` — газ / тормоз и задний ход
- `A/D` — руль
- `Z/X` — левый / правый поворотник
- `H` — аварийная сигнализация
- `R` — вернуть автомобиль на старт

Импортируйте `project.godot` в Godot 4.x и запустите проект.
